# Fredonia avatar maker

An Open Peeps avatar builder people can embed in a LibGuide. Visitors pick an outfit, hair, face, facial hair, glasses and a mask across three views (head and shoulders, standing, sitting), add patches to their clothes, and download the result as SVG or PNG. Everything runs in the browser: no accounts, no tracking, no build step.

## Files

- `index.html`, `app.js`: the tool
- `parts/parts.js`: every Open Peeps part as plain SVG, generated by `tools/extract-parts.mjs`
- `config/layers.js`: positions, hidden items and clash rules. The layer checker writes this file
- `patches/`: the patches people can add to their clothes, listed in `patches/patches.js`

## Adding Fredonia patches

1. Put each file (SVG preferred; PNG with a transparent background also works) in `patches/`.
2. Add a line to `patches/patches.js`:

   ```js
   { id: 'fredonia-wordmark', name: 'Fredonia wordmark', src: 'patches/fredonia-wordmark.svg' },
   ```

3. Delete the placeholder patches you don't want.

## Checking and fixing layers

Open the tool with `?admin=1` on the end of the address, eg `https://chilburger.github.io/fredonia-peeps/?admin=1`. A layer checker appears under the controls. Visitors never see it.

- **Check:** choose hair, faces, facial hair, glasses, masks, head-on-outfit (for the current view) or default patch spot.
- **Show all:** draws every item in that category on your current avatar, so broken ones stand out. Click one to open it.
- **Nudge:** arrow keys move the selected item (Shift for steps of 10), `+`/`-` resize it, `,`/`.` tilt a head, `[`/`]` step through items, `K` marks an item checked and moves to the next one.
- **Hide from visitors:** removes an item from the pickers without deleting it.
- **Doesn't work with:** records a clash between the item and something you have selected in another category, or with anything in that category ("any"). Visitors then can't combine them: an optional part (facial hair, glasses, mask) is removed automatically, and an option that clashes with the outfit, hair or face is greyed out.
- **Save:** changes are kept in your browser as you work. Click **Download layers.js** and replace `config/layers.js` in this repository to publish them.

## Embedding in a LibGuide

Add a **Media/Widget** asset (Add/Reorder → Media/Widget) and paste:

```html
<button id="hunt-btn" type="button" aria-expanded="false" aria-controls="peeps-frame-wrap"
  style="background:#1f4e9c;color:#fff;border:0;border-radius:8px;padding:10px 18px;font-size:16px;cursor:pointer">
  Make your avatar
</button>
<div id="peeps-frame-wrap" hidden style="margin-top:12px">
  <iframe src="https://chilburger.github.io/fredonia-peeps/" title="Avatar maker"
    loading="lazy" style="width:100%;max-width:960px;height:720px;border:1px solid #ccc;border-radius:8px"></iframe>
</div>
<script>
  (function () {
    var btn = document.getElementById('hunt-btn'), wrap = document.getElementById('peeps-frame-wrap');
    btn.addEventListener('click', function () {
      var open = wrap.hidden; wrap.hidden = !open; btn.setAttribute('aria-expanded', open);
    });
    if (location.hash === '#hunt-btn') { wrap.hidden = false; btn.setAttribute('aria-expanded', 'true'); }
  })();
</script>
```

To show the tool without a button, paste only the `<iframe>`.

## Rebuilding the parts

```bash
npm pack @opeepsfun/open-peeps @dicebear/open-peeps
```

Unpack both, then run:

```bash
node tools/extract-parts.mjs <opeepsfun package dir> <dicebear package dir> > parts/parts.js
```

The script reads the package files as text and never runs their code.
